* **Visual Concept:** A side-by-side contrast of two heatmaps. Left: Smooth, organic, noisy human mouse curve. Right: Segmented, piecewise-linear Bézier trajectory generated by an automation script with unnatural mathematical curvature.

    $$\text{Output: } P_{\text{synthetic}} \in [0.0, 1.0]$$
* **Speaker Notes:** "Humans don't move mice with mathematical equations. Our muscles twitch and waver. We convert mouse trajectories into image heatmaps and use a fast computer vision model to spot machine-generated motion in 8 milliseconds."

* **Speaker Notes:** "Attackers prompt LLMs to write unique bios for each account so string matching fails. But their underlying semantic meaning stays identical. Our local vector model catches them instantly without sending data to third-party clouds."

## Slide 6: The Graph Engine — Louvain Modularity Community Detection
* **Slide Type:** Graph Theory & Algorithm Deep-Dive
* **Visual Concept:** A network diagram where edge thickness represents similarity. The Louvain algorithm runs in stages, automatically drawing glowing boundary hulls around the tightly knit bot syndicate while ignoring genuine human nodes.
* **The Mathematics:**
  * As sessions arrive, ShadowGram constructs an in-memory dynamic adjacency matrix using NetworkX.
  * An edge $(u, v)$ is drawn between two sessions if their composite similarity $S_{\text{comp}} \ge 0.78$ across 3 or more layers.
  * Instead of guessing the cluster count $k$ (which fails in open banking), we optimize **Newman-Girvan Modularity ($Q$)**:
    $$Q = \frac{1}{2m} \sum_{ij} \left[ A_{ij} - \frac{k_i k_j}{2m} \right] \delta(c_i, c_j)$$
  * Any community with $Q > 0.60$ and node count $\ge 3$ is mathematically classified as a coordinated fraud syndicate ($P < 10^{-5}$).
* **Speaker Notes:** "We don't need to know beforehand how many bots are attacking. Louvain modularity automatically discovers the exact boundaries of the syndicate, separating the criminal gang from ordinary customers."
