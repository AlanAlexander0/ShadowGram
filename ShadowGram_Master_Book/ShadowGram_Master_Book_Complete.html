1.1 The Generation Shift in Cyber-Attacks

Cyber-attacks have evolved through three distinct technical generations:

  • Generation 1 (Scripted Automation, 2016): Hardcoded Python cURL scripts and static proxy lists. Fast execution, but blocked by Cloudflare TLS fingerprints and reCAPTCHA checkboxes.
  • Generation 2 (Human Click Farms, 2021): Low-wage human operators solving challenges and typing credentials manually. High operational cost and slow speed.
  • Generation 3 (Autonomous AI Swarms, 2026): Distributed agent runtimes powered by local language and vision models. Each bot instance executes independent browser interactions, solves visual CAPTCHAs, randomizes mouse movement, and rotates residential mobile proxies.

3.2 The 5 Composite Physics Layers

Layer 1: Temporal Rhythm ($S_{\text{time}}$)

Measures the inter-arrival delta $\Delta t$ between sequential form events across sessions. Coordinated bot runners dispatch requests in tight bursts ($\Delta t < 50\text{ms}$). Natural human arrivals follow an independent Poisson distribution.

Layer 2: Navigation Finite State Machine ($S_{\text{nav}}$)

Calculates the Longest Common Subsequence (LCS) across navigation paths (e.g. /auth $\to$ /kyc $\to$ /submit). Sessions with route similarity $\ge 0.85$ are flagged.

Layer 3: Kinetic Cursor Spectrogram Analysis ($S_{\text{kin}}$)

Biomechanical Discovery: 8–12 Hz Physiological Tremor
Human hands exhibit involuntary neuromotor tremor at 8 to 12 Hz. Bézier curves have smooth mathematical derivatives where jerk (the 3rd derivative $\frac{d^3x}{dt^3}$) is zero or constant.

We convert mouse paths $[x, y, t]$ into a 128x128 acceleration spectrogram image. A lightweight 2D-CNN in ONNX Runtime evaluates the spectrogram in $< 10\text{ms}$ on CPU, outputting $P_{\text{synthetic}} \in [0.0, 1.0]$.

Layer 4: Dense Semantic Vector Forensics ($S_{\text{sem}}$)

Bots use LLMs to write loan explanations. The words are different, but the semantic concept is identical. We compute 384-dimensional dense vectors using local CPU model all-MiniLM-L6-v2 ($< 15\text{ms}$): 

Cosine_Similarity(A, B) = (A · B) / (||A|| ||B||) >= 0.88

Layer 5: Environmental Hardware Entropy ($S_{\text{env}}$)

Extracts non-PII hardware entropy signals: AudioContext oscillator decay, WebGL canvas render hashes, and system clock skew.

3.3 Graph Community Detection (Louvain Modularity Math)

An edge $(u, v)$ is created if composite similarity $S_{\text{comp}} \ge 0.78$ across at least three layers: 

S_comp(u, v) = w_time*S_time + w_nav*S_nav + w_sem*S_sem + w_kin*S_kin + w_env*S_env

We partition the graph using Newman-Girvan Modularity ($Q$): 

Q = (1 / 2m) * sum_ij [ A_ij - (k_i * k_j) / (2m) ] * delta(c_i, c_j)

Any cluster with $Q > 0.60$ and node count $\ge 3$ is mathematically isolated as a syndicate ($P < 10^{-5}$).

APP Master Glossary & Reference Bibliography

Master Glossary (ASD-STE100 Technical Terms)

  • Autonomous AI Swarm: A group of software agents that coordinate actions across multiple accounts without human control.
  • Synthetic Identity: A fabricated identity made by combining authentic government identification numbers with fabricated personal data.
  • Kinetic Jerk: The third mathematical derivative of position with respect to time ($d^3x/dt^3$). Measures the rate of change of acceleration.
  • Louvain Modularity ($Q$): A mathematical algorithm that measures the density of links inside communities compared to links between communities.
  • Denial-of-Wallet (DoW): A cyber-attack that forces an organization to spend financial resources on third-party API verification fees.
  • Why Card: An interface window that displays verifiable factual evidence explaining why accounts were grouped into a cluster.
