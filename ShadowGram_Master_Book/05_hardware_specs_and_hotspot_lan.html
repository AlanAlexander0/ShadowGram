5.3 Hotspot LAN Configuration (Google Pixel + Jio SIM)

Mandatory Networking Rules
1. FastAPI Binding: On Laptop 2, start FastAPI with uvicorn main:app --host 0.0.0.0 --port 8000. Binding to localhost blocks external laptops.
2. IP Discovery: Run hostname -I on Linux to find your local IP (e.g. 192.168.43.2). All laptops target this IP.
3. Google Pixel Advantage: Stock Android does not enable AP client isolation. All laptops can ping each other.
4. Zero Docker: Run Python venv and Node.js natively to avoid Windows WSL2 bridge network isolation.
